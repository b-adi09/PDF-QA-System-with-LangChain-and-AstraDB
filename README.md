# PDF-QA-System-with-LangChain-and-AstraDB
Developed a scalable document question-answering system using LangChain, Astra DB, and OpenAI embeddings. Extracted text from PDFs with PyPDF2, optimized token usage with a custom text-splitting mechanism, and deployed Cassandra as a vector database for high-performance similarity search. Integrated LLMs for accurate and real-time query resolution.
